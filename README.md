# MoriStorage Web Game Demo

This branch contains a small Phaser 3 demo scaffold (branch: `web-game`) that shows a tiny top-down scene where you can walk, talk to an NPC, and open a menu.

How to run locally

- Option A (quick, Python):
  - python3 -m http.server 8000 (from repository root) and open http://localhost:8000/index.html
- Option B (Node):
  - npx http-server -c-1

Notes
